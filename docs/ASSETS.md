# Bundled brand assets

- `brand_instagram.png`: Instagram 2022 application icon, sourced from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Instagram-Icon.png), where it is identified as an Instagram-authored trademark consisting of simple geometry. The transparent bundled artwork is always used so Android does not add the installed adaptive icon's white plate.
- `brand_youtube.png`: YouTube full-color button icon (2024), sourced from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:YouTube_full-color_icon_(2024).svg). The transparent bundled artwork identifies the YouTube blocking target without relying on an installed launcher icon.
